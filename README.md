# Тревел лента на Кинескопе

Локальный прототип вертикальной ленты из 10 роликов. Исходный список и снимок офферов лежат в `feed-data.js`: для каждого исходного ролика там хранится ID, а ссылка на воспроизведение собирается как `https://kinescope.io/<ID>`. Сами видео загружаются плеером Кинескопа. Загруженные через админку файлы хранятся в локальной `.local-data/uploads/` и воспроизводятся через встроенный HTML5-плеер.

## Локальный просмотр и админка

```bash
python3 dev_server.py
```

- Лента: http://127.0.0.1:8765/
- Админка: http://127.0.0.1:8765/admin.html

В админке есть разделы «Видео», «Авторы», «Товары», «Отчёты» и «Настройки». Для авторов и товаров доступны создание, поиск, редактирование и удаление. Товары можно скрывать и публиковать. Автора можно назначить ролику, товар — привязать к офферу. Выпадающие списки оформлены единым компонентом, иконки взяты из переданного набора uicons.

Ролик можно добавить по ссылке Кинескопа или загрузить MP4/WebM до 150 МБ, назначить автора, категорию, теги, коллекцию и постер. При редактировании ролика Кинескопа показывается полный адрес источника с возможностью открыть его; ID исходного ролика остаётся неизменным. Для ролика доступны два оффера из каталога товаров или с ручным вводом. Карточки можно искать и фильтровать; меню позволяет открыть предпросмотр, отредактировать, скрыть, опубликовать, скачать локальный файл или удалить добавленный ролик. Исходные 10 роликов можно редактировать и скрывать. Одну коллекцию можно открыть по ссылке вида `/?collection=Москва`.

Отчёты собирают локальные события открытий роликов, лайков, кликов по офферам и времени просмотра после запуска этого сервера. Исторических данных и заказов Streamerce здесь нет. Таблицу можно выгрузить в CSV.

Изменения и загрузки сохраняются в `.local-data/` на этом компьютере. Директория не коммитится в Git. Сервер слушает только `127.0.0.1` и не имеет авторизации: **не выставляйте его в публичную сеть**. При запуске через обычный `python3 -m http.server` или на GitHub Pages лента работает с исходными данными, а админка недоступна для записи. Чтобы опубликовать изменения для всех пользователей, нужен отдельный сервер с хранилищем и авторизацией.

После правки `feed.js` или `feed.css` для GitHub Pages увеличьте версию `?v=` в `index.html`, чтобы сбросить браузерный кеш. На локальном сервере достаточно обновить страницу.

Плеер на телефоне нужно проверять отдельно: первый ролик пытается стартовать со звуком, а если браузер запрещает такой автозапуск, запускается без звука и показывает кнопку его включения. После свайпа следующий ролик стартует автоматически. Лента запускает только выбранный ролик после завершения прокрутки, а предыдущий плеер оставляет на паузе для быстрого возврата. Следующий плеер заранее не создаётся, чтобы одновременно не загружать два экземпляра одного ролика при быстром свайпе. Если запуск не состоялся, лента повторяет попытку и показывает кнопку повтора при ошибке. Во время первого запуска виден постер, затем состояние загрузки показывает сам Кинескоп. Шкала прогресса поддерживает перемотку, при скрытии вкладки видео ставится на паузу.
